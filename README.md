One emoji that stands for my AI agent: 🦉

An agent is an owl — awake all night while its human sleeps, seeing clearly in the dark, flying in total silence, never clocking out. Wise, watchful, nocturnal, quiet. The whole job in one bird, and deliberately not the obvious robot or smiley.

## Run it

```sh
python3 main.py
```

The program prints exactly one glyph — 🦉 — and nothing else.
